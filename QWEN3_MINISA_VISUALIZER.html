Run on the real FEATHER RTL

Download the program JSON, then run from the repository root in the project's Python/ModelSim environment (build once with RTL/fp16/run_sim.sh build):

python tb/scripts/minisa_visualizer_program.py \
  --program feather_q_proj_tile.json \
  --out /tmp/feather-program-run --rtl

This loads the same packed words into minisa_feather_system through the existing RTL testbench. By default, the runner creates deterministic synthetic operands and checks bit-exact results; use --a-npy and --b-npy for your FP16 matrices. Choose a new output directory for each run.

The offline browser preview models control, not numerical tensor arithmetic, RTL timing, or a physical FPGA connection. The local RTL runner performs hardware simulation. Large runs require an explicit work limit increase; some projection images exceed the testbench's fixed memory capacity even then. ISA export is supported for all nine; tile and full 128³ attention programs fit the default runner limits.
